Nexus Mod-ID Sync — Feature Workflow

End-to-end flow covering initial ingestion auto-rename, mismatch detection, manual mod-ID assignment, and update path. Based on ModCard.tsx in the RivalNxt repository.

📋 Phase Breakdown
Phase 1 · Auto-rename on Ingestion

Initial Download

When a mod archive lands in the downloads folder, the ingestion pipeline immediately checks the filename against the Nexus API response.

  • Build expected name: <name>-<modid>-<version>-<timestamp>.<ext>
  • If filename matches → store as-is
  • If it matches the contents but not the name → rename silently
  • If contents don't match → mark as needsManualId
Phase 2 · Mismatch Detection

Convention Check

After ingestion (and on every subsequent load), the app evaluates whether each ModCard has a confirmed backendModId linkage.

  • Parse filename → extract segments by - delimiter
  • Validate segment 2 as a numeric Nexus mod ID
  • Query /v1/games/:game/mods/:id/files for confirmation
  • No match → show "Assign Mod ID" badge on card
Phase 3 · Manual Assignment

User Override

User clicks "Assign Mod ID" on a card. A modal/inline input appears, the user types or pastes the Nexus mod ID.

  • Fetch Nexus API to validate the supplied mod ID
  • Compare API's file list against local file contents hash
  • If match found → rename local file(s) to canonical format
  • Persist mapping in local DB (mod_id_overrides table)
Phase 4 · Update Path

Same Logic on Update

When hasUpdate is true and the user triggers an update download, the same rename pipeline runs on the newly downloaded file.

  • Re-use stored backendModId from DB override if present
  • Fetch latest file entry from Nexus API
  • Rename incoming archive to canonical convention
  • Replace old file; update localVersionKey

🔧 Canonical Filename Utility
/**
 * Build the canonical Nexus filename for a mod file.
 * Convention: {name}-{modId}-{version}-{timestamp}.{ext}
 */
function buildCanonicalFilename(
  modName: string,
  modId: number,
  version: string,
  uploadedTimestamp: number,  // unix epoch from Nexus API
  ext: string                   // "zip" | "7z" | "rar" | ""
): string {
  const safeName = modName
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, "-")
    .replace(/^-|-$/g, "");
  const suffix = ext ? `.${ext}` : "";
  return `${safeName}-${modId}-${version}-${uploadedTimestamp}${suffix}`;
}

/**
 * Check if a local filename already matches canonical convention.
 * Returns the extracted modId if it does, null otherwise.
 */
function extractModIdFromFilename(filename: string): number | null {
  // strip extension, split by "-", segment[1] should be numeric modId
  const base = filename.replace(/\.[^.]+$/, "");
  const parts = base.split("-");
  if (parts.length < 4) return null;
  const maybeId = Number(parts[1]);
  return Number.isFinite(maybeId) && maybeId > 0 ? maybeId : null;
}
